Getting Started

ForgeAPI provides an OpenAI and Anthropic compatible interface for accessing high-performance language models through a single unified endpoint.

Base URL
https://sol-bridge-gateway.vercel.app/v1

Authentication

All requests to ForgeAPI endpoints require an API key passed in the Authorization header using the Bearer schema:

Authorization Header
Authorization: Bearer forge_live_••••••••••••••••

Chat Completions

Send chat completion requests via POST /v1/chat/completions or POST /v1/messages with streaming support enabled.

cURL Example
curl "https://sol-bridge-gateway.vercel.app/v1/chat/completions" \
  -H "Authorization: Bearer forge_live_e3c9uk4fuzqrl7d9gyxu2n9ohczufx8x" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.6-sol",
    "messages": [
      {"role": "user", "content": "Explain binary search in Python."}
    ],
    "stream": true
  }'

Errors & Rate Limits

If an API key has depleted all credits or hits concurrency thresholds, ForgeAPI returns standard HTTP status codes:

401 UnauthorizedMissing or invalid API key
402 Payment RequiredInsufficient balance — please add credits
429 Too Many RequestsRate limit exceeded
